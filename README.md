# EconoMaster 🚀

**EconoMaster** is an interactive web-based sovereign economic, trade, and defense engine. Explore, analyze, and simulate macroeconomic concepts, monetary levers, dynamic international trade agreements, national defense outlays, and strategic sovereign policies—with a primary focus on Canada's role in the global economy.

🔗 **Live Website:** <https://breaultalex44-cmd.github.io/EconoMaster/>

---

## 📌 Engine Capabilities & Core Features

- **Dynamic Sovereign Policy Engine:** Fine-tune 10+ granular macroeconomic metrics, including property taxes, federal infrastructure multipliers, wealth tax, carbon pricing, union bargaining power, R&D innovation rebates, and FDI incentives.
- **15 Canadian Key Industries & FTAs:** Live modeling of major sectors (Oil & Gas, Tech/AI, Aerospace, Real Estate, Banking, etc.) paired with dynamic Free Trade Agreement (FTA) negotiations with realistic diplomatic success rates and AI-powered negotiators.
- **Department of National Defence (DND) Matrix:** Direct production of guided interceptors, hypersonic missiles, NORAD radar upgrades, and full management of Non-Proliferation Treaty (NPT) compliance.
- **Classified Sovereign Nuclear Program Console:** Multi-stage nuclear weapon development framework featuring 6-quarter feasibility analysis, 12-quarter warhead fabrication, and a 3-warhead stockpile/inventory UI with severe macroeconomic fallout mechanics.
- **Fail Conditions & Failure Mechanics:** Maintain voter approval above 0%. Remaining at 0% voter approval for 4 consecutive quarters triggers political collapse, legislative deadlock, and a full Game Over screen.
- **Controlled Remembering & Portable Thumb Tab System:** Automatic state persistence via browser storage, alongside a **"I want to cut the line"** button that unlocks JSON save file export, import, and hard reset options.
- **Live Visual Analytics & Press Ledger:** Integrated Chart.js visualizations tracking real-time GDP growth, CPI inflation, bond yields, debt-to-GDP ratios, and a dynamic financial event feed.

- **Frontend:** HTML5, Modern JavaScript (ES6+), Chart.js, FontAwesome 6

## 🚀 Getting Started

To run EconoMaster locally on your machine, follow these steps:

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Edge, Safari) and Git installed.

### Installation & Launch

1. **Clone the repository:**
   ```bash
   git clone https://github.com/breaultalex44-cmd/EconoMaster.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd EconoMaster
   ```

3. **Open the project:**
   Simply double-click `index.html` in your web browser, or launch a quick local server using Python:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
