# EconoMaster 🚀

**EconoMaster** is an interactive web-based platform dedicated to exploring, analyzing, and understanding economic concepts, indicators, and global financial dynamics—with a special focus on Canada's role in the global economy.

🔗 **Live Website:** <https://breaultalex44-cmd.github.io/EconoMaster/>

## 📌 Features

* **Interactive Economic Engine:** Visualize economic indicators, trends, and data relationships.

* **Global & Canadian Focus:** Deep dives into macroeconomic policies, trade, resources, and GDP dynamics.

* **Clean UI/UX:** Responsive design optimized for reading, interactive learning, and data exploration.

* **Lightweight & Fast:** Built for seamless web performance via GitHub Pages.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)

* **Styling:** Custom CSS / Tailwind CSS *(adjust if using a framework)*

* **Deployment:** GitHub Pages

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

### Prerequisites

You only need a modern web browser and basic git installed.

### Installation

1. **Clone the repository:**

   ```
   git clone https://github.com/breaultalex44-cmd/EconoMaster.git
   
   ```

2. **Navigate to the project directory:**

   ```
   cd EconoMaster
   
   ```

3. **Open the project:**
   Simply open `index.html` in your favorite web browser, or use a local server extension (like Live Server in VS Code):

   ```
   # If using Python for a quick local server:
   python -m http.server 8000
   
   ```

   Then visit `http://localhost:8000` in your browser.
