# EconoMaster 🚀

**EconoMaster (v5.5)** is an interactive web-based sovereign economic, trade, and defense engine. Explore, analyze, and simulate macroeconomic concepts, monetary levers, dynamic international trade agreements, national defense outlays, multilateral associations, and strategic sovereign policies—with a primary focus on Canada's role in the global economy.

🔗 **Live Website:** <https://breaultalex44-cmd.github.io/EconoMaster/>

---

## 📌 Engine Capabilities & Core Features

- **Dynamic Sovereign Policy & Monetary Engine:** Fine-tune baseline tax and monetary controls (PIT, CIT, GST/HST, carbon pricing, Bank of Canada overnight rate, reserve ratio, capital gains inclusion) alongside **10 configurable sovereign metrics**—including property tax assessment base, federal infrastructure multiplier, clean energy investment tax credit, resource royalty surcharge, wealth tax, bank transactions levy, import tariff surcharge base, labor union bargaining power index, federal R&D innovation rebate, and FDI capital incentive rate.
- **Public Services & Appropriations:** Manage quarterly federal funding across 9 public service pillars (healthcare, education, research & AI grants, policing, transport, environment, housing, veterans affairs, and childcare).
- **15 Canadian Key Industries, Dynamic FTAs & AI Negotiator:** Live modeling of 15 sectors (Oil/Gas/Mining, Automotive/Heavy Mfg, Tech/AI/Software, Real Estate/Construction, Agriculture/Food, Banking/Finance, Aerospace/Defense, Forestry, Pharma/Biotech, Clean Energy, Telecom, Tourism, Fisheries, Shipping/Rail/Logistics, and Chemicals/Plastics) with custom tariffs, export taxes, subsidies, and price benchmarks. Includes **11 bilateral/regional FTAs** with diplomatic "Request to Sign" ratification rolls and an **AI-powered live negotiation engine**.
- **UN & Multilateral Associations (10 Bodies):** Manage membership funding and alignment across bodies such as the UN Core Budget, UN Climate Adaptation Fund, WHO, NATO, WEF, Commonwealth, WTO, Arctic Council, IEA, and Global AI & Cyber Security Coalition.
- **Department of National Defence (DND) Matrix:** Adjust personnel quotas, reserves, cyber warfare, aerospace, naval/Arctic patrols, and NORAD radar infrastructure, direct domestic production of guided interceptors and hypersonic/cruise munitions, run Joint Staff readiness audits, and toggle **Non-Proliferation Treaty (NPT)** compliance.
- **Classified Sovereign Nuclear Program Console & Canvas Sequence:** Multi-stage nuclear deterrent program featuring a 6-quarter feasibility analysis, a $1.5B/quarter cabinet funding decision sheet, 12-quarter warhead fabrication, a stockpile UI (Tactical W80-4, Thermonuclear B83, Salted Cobalt-60) with warhead dismantlement options, and an interactive HTML5 Canvas launch/detonation sequence with emergency abort controls and severe economic/diplomatic fallout.
- **Fail Conditions & Failure Mechanics:** Maintain voter approval above 0%. Remaining at 0% voter approval for 4 consecutive quarters triggers political collapse, legislative deadlock, and a full Game Over screen.
- **Controlled Remembering & Portable Thumb Tab System:** Automatic state persistence via `localStorage` on quarter advances, alongside the **"I want to cut the line"** button in the footer that unlocks JSON save file export, import, and forced memory reset.
- **Live Visual Analytics & Press Ledger:** Integrated Chart.js visualizations tracking GDP growth, CPI inflation, bond yields, and debt-to-GDP ratios, paired with a real-time financial and geopolitical event ledger.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern JavaScript (ES6+), HTML5 Canvas, Chart.js, FontAwesome 6, Google Fonts (`Inter`)
- **Styling:** Tailwind CSS (via CDN)
- **Persistence:** Browser `localStorage` & Portable JSON Save/Load
- **Architecture:** Portable Single-File Web Application (`index.html`)
- **Deployment:** GitHub Pages

## 🚀 Getting Started

To run EconoMaster locally on your machine, follow these steps:

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Edge, Safari) and Git installed.

### Installation & Launch

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/breaultalex44-cmd/EconoMaster.git](https://github.com/breaultalex44-cmd/EconoMaster.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd EconoMaster
   ```

3. **Open the project:**
   Simply double-click `index.html` in your web browser, or launch a quick local server using Python:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
